# DATA.md

## Схема данных

Ниже описаны поля основного синтетического набора для темы **«ПассажирМаршрут»**.

### Основные поля

| Поле | Тип | Смысл | Допустимые значения |
| --- | --- | --- | --- |
| `passenger_id` | целое число | Уникальный идентификатор пассажира | 1, 2, 3, ... |
| `age` | число с пропусками | Возраст пассажира | 18–80, 5% строк — пропуск |
| `deck` | категориальный | Палуба начала маршрута | `lower`, `middle`, `upper` |
| `distance_m` | число | Длина маршрута до места сбора | 20–300 м |
| `luggage_count` | целое число | Количество предметов багажа | 0–3 |
| `briefing` | бинарный | Прошёл ли инструктаж | 0 / 1 |
| `arrived_in_time` | бинарный | Успел ли пассажир вовремя | 0 / 1 |

## Скрытые переменные генератора

Эти поля существуют только внутри генератора и не используются как признаки модели.

| Поле | Смысл |
| --- | --- |
| `actual_speed` | истинная скорость движения |
| `start_delay` | задержка перед началом движения |
| `travel_time` | чистое время прохождения маршрута |
| `random_delay` | случайная дополнительная задержка |
| `total_time` | итоговое время прибытия |

## Правила генерации

1. Основной набор содержит **3000 строк**.
2. Возраст скрывается в **5%** строк.
3. Целевой класс определяется по порогу времени: если `total_time` не превышает `time_limit_sec`, то `arrived_in_time = 1`, иначе `0`.
4. Скрытые переменные не попадают во входы модели.
5. Генератор основной версии фиксируется как **`v2`**.
6. Для всех стохастических операций используется фиксированный seed из `src/constants.py`.

## Разделение выборки

Для основных экспериментов используется стратифицированное разбиение **60/20/20**:

- `train` — обучение;
- `val` — валидация;
- `test` — итоговая проверка.

Разбиение выполняется один раз с фиксированным seed. Названия файлов выборок должны быть строго такими же, как в проекте: `train`, `val`, `test`.

## Файлы данных

Согласно соглашению проекта, основные файлы данных лежат в `data/raw/`, а разбиения — в `data/splits/`.

- основной набор: `data/raw/passengers_v2_seed42.csv`
- скрытые переменные: `data/raw/passengers_v2_seed42_hidden.csv`
- train: `data/splits/train.csv`
- val: `data/splits/val.csv`
- test: `data/splits/test.csv`
- пробный набор: `data/trial/mock_passengers.csv`

## Проверки качества данных

Перед обучением нужно проверить:

- уникальность `passenger_id`;
- допустимые значения `deck` и `briefing`;
- корректные диапазоны `age`, `distance_m`, `luggage_count`;
- отсутствие скрытых переменных во входах модели;
- отсутствие утечки данных из `val` и `test` при предобработке;
- воспроизводимость генерации при одинаковом seed.

## Пробные данные

В репозитории есть отдельный пробный набор в `data/trial/`. Он нужен для отладки и проверки генератора, но не должен использоваться как источник итоговых метрик.
